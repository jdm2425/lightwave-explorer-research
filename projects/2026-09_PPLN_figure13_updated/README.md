# Updated Figure 13: matched chirped-vs-fixed PPLN comparison

This patch creates a new project:

`projects/2026-09_PPLN_figure13_updated/`

The scientific choice is deliberate: it uses the existing
`PPLN_FIXED_21p75um.txt` as the source of truth for the pump, seed, material and
numerical grid. Four 500 um linearly chirped PPLN designs are then generated by
changing only the poling geometry:

- 18–24 um
- 19.4–22 um
- 20–24 um
- 17.5–20.4 um

The existing fixed 21.75 um output is reused by the analysis rather than
rerun unnecessarily.

This produces:
- a reconstructed/updated Figure 13 with the four chirped designs plus the
  fixed 21.75 um spectrum;
- a focused fixed-21.75-vs-chirped-20–24 comparison;
- a CSV of target-band energy and spectral-shape metrics.

Why use the current -1230 fs^2 baseline instead of the old -500 fs^2 Figure 13?
Because the report already introduces -1230 fs^2 as the estimated Chimera input
chirp, and the newly validated fixed-period scan uses that input. Matching this
baseline isolates the effect of poling geometry. The old -500 fs^2 condition is
preserved in the provenance note for historical reproducibility.
