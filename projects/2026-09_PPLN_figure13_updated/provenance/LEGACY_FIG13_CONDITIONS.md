# Legacy Figure 13 conditions in the current report

The current report states that the original Figure 13 chirped-design comparison used:

- crystal length: 500 um
- pump energy: 0.025 uJ = 25 nJ
- pump GDD: -500 fs^2
- pump centre: approximately 800 nm
- pump bandwidth: described as approximately 100 nm
- coherent MIR seed: 10 nJ
- seed centre: approximately 56 THz (about 5 um)
- seed bandwidth: approximately 75 THz

The report does not fully specify every implementation parameter needed for a
bit-for-bit rerun (for example all super-Gaussian orders and beam parameters).

For the NEW Figure-13 comparison, this project therefore does not attempt to
reconstruct those unspecified legacy details. Instead it copies the complete
current 21.75 um fixed-period input and changes only the poling geometry.

This is the appropriate dataset for adding the fixed-period trace because it
makes the fixed and chirped simulations directly matched.
