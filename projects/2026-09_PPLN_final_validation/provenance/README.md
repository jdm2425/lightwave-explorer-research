# Final PPLN validation

Purpose:

1. Validate the numerical grid for the 20-24 um chirped, GDD=0 crystal.
2. Test whether the fixed-vs-chirped result is sensitive to the artificial
   coherent MIR seed.

Existing baseline:
- seed energy = 10 nJ
- seed delay = 0 fs

Additional seed cases:
- seed energy = 1 nJ
- seed delay = -100 fs
- seed delay = +100 fs

Each seed condition is evaluated for:
- fixed 21.75 um
- chirped 20-24 um
